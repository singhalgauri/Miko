# Demo Video Shot List & Production Checklist

> Owner: Person 3  
> Purpose: Camera, screen-recording angles, zoom cues, and UI states for video recording  
> Resolution: 1920x1080 (1080p, 60fps)

---

## Shot Sequence

1. **Shot 1 (0:00 - 0:10): The Chaos**
   - Screen record messy desktop with random downloaded files and browser notifications.
   - Zoom in on system tray showing Miko icon running quietly.

2. **Shot 2 (0:10 - 0:20): App Hero Launch**
   - Smooth opening of Miko window.
   - Dark theme dashboard displaying system status, active provider, and task metrics.

3. **Shot 3 (0:20 - 0:45): Inbox Triage Execution**
   - Click "Run Inbox Triage" button.
   - Show fast streaming response powered by Nebius Token Factory.
   - Highlight categorized list (Urgent, Newsletter, Action Required).

4. **Shot 4 (0:45 - 1:00): Permission Interception**
   - Show approval card popping up: "Agent wants to create draft reply to Client Inquiry".
   - Click "Approve" button, show immediate confirmation.

5. **Shot 5 (1:00 - 1:25): Document Search & Citations**
   - Navigate to Documents page.
   - Type query: "contract termination clause".
   - Show matching PDF excerpt with highlighted page citation badge `[contract.pdf:p4]`.

6. **Shot 6 (1:25 - 1:40): Daily Briefing**
   - Navigate to Briefing page.
   - Show calendar timeline, summary bullet points, and "While you were away" catch-up block.

7. **Shot 7 (1:40 - 2:00): File Organiser in Action**
   - Navigate to File Organiser. Click "Organise Downloads".
   - Split screen showing files moving into clean categorized subfolders (`Invoices/`, `Images/`).

8. **Shot 8 (2:00 - 2:15): Activity Log & Undo**
   - Navigate to Activity Log table.
   - Show `provider: nebius` column.
   - Click "Undo" button on top entry.
   - Watch the moved file pop right back to its original location.

9. **Shot 9 (2:15 - 2:35): Dual Mode & Privacy Banner**
   - Navigate to Settings. Switch provider to `Nebius (Token Factory)`.
   - Point cursor to prominent orange banner: *"Prompts leave this machine"*.
   - Switch back to `Local (Ollama)`: banner disappears, showing *"100% offline mode"*.

10. **Shot 10 (2:35 - 2:45): Benchmark Performance**
    - Display benchmark chart comparing Ollama 4B local vs Nebius Token Factory.
    - Highlight TTFT and token throughput gains.

11. **Shot 11 (2:45 - 3:00): GitHub Repo & License**
    - Show GitHub repo overview, Apache 2.0 license, and Phase 2 roadmap cards.
    - End card with repository URL and hackathon track badge.
